# Chatbot Engine

## Overview
A simple AI-style chatbot engine using rule-based responses.

---

## Features
- Rule-based conversation system
- Interactive chat loop
- Basic intent matching

---

## Files
- `responses.py` → chatbot response rules
- `chat.py` → interactive chatbot interface

---

## Usage

```bash
python chat.py
```

---

## Example Conversation

```text
You: hello
Bot: Hi! How can I help you?

You: how are you
Bot: I am doing great.

You: bye
Bot: Goodbye!
```
